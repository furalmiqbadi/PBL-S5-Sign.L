# 📁 Folder: `assets/animations/`

## 🎯 Fungsi Utama
Tempat menyimpan file animasi Lottie (.json) untuk menciptakan antarmuka interaktif dan "juicy" ala Duolingo.

---

## 📌 Contoh Isi:
- Animasi maskot burung/karakter Sign.L saat menyapa (`mascot_idle.json`, `mascot_celebrate.json`)
- Feedback jawaban benar dengan centang hijau membal (`correct_feedback.json`)
- Feedback jawaban salah (`incorrect_feedback.json`)
- Animasi api streak menyala (`fire_streak.json`)
- Animasi naik level / kembang api (`level_up.json`)
