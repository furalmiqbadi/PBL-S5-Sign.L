# 📁 Folder: `lib/views/widgets/`

## 🎯 Fungsi Utama
Menyimpan komponen-komponen UI *reusable* (dapat dipakai ulang di banyak layar) yang memberikan identitas visual khas ala Duolingo.

---

## 📌 Apa yang Diisi di Sini?
- `duo_button.dart`:
  - Tombol dengan efek 3D (shadow tebal di bawahnya yang membal ke bawah saat ditekan dengan `flutter_animate`).
- `duo_progress_bar.dart`:
  - Bar indikator kemajuan belajar dengan ujung melengkung (rounded) dan warna gradasi hijau/kuning cerah.
- `duo_app_bar.dart`:
  - Custom AppBar yang menampilkan indikator streak, gems, dan hearts (nyawa).
- `loading_overlay.dart`:
  - Indikator putaran loading transparan saat aplikasi menunggu respon jaringan atau inferensi model.
